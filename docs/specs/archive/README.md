# Shipped specs (archive)

Working specs that have **shipped and been reconciled** into the long-term
reference docs live here, renamed with the date they were archived
(`YYYY-MM-DD-name.md`).

These are kept for history — intent, scope, rationale, and the design detail
the code alone doesn't record. **They are not a source of truth.** Anything
still true about current behaviour has already been folded into
[`../../reference/`](../../reference/); if this archive and a reference doc ever
disagree, the reference doc wins. Don't link to a file here as if it were
canonical, and don't build new work off it without re-confirming against the
reference docs and the code.
